# Development Guidelines

## Coding conventions

- Use TypeScript everywhere for typed application code.
- Prefer small, reusable components in shared packages.
- Keep environment variables in .env files and document them in .env.example.
- Use meaningful commit messages and branch names.

## Workflow

1. Create a feature branch.
2. Implement changes with tests where practical.
3. Run npm run build before submitting work.
4. Review environment and deployment configuration before release.
