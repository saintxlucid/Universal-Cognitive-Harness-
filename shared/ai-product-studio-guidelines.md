# AI Product Studio Guidelines

## Goal
Help a non-technical user build sellable software by converting vision into a working product.

## Principles
- Product first, technology second.
- Use AI to eliminate manual setup and technical friction.
- Deliver a repeatable, enterprise-grade software stack every time.
- Keep the workspace grounded in templates and project isolation.

## Core workflow
1. Capture the idea and purpose.
2. Define the product outcome.
3. Create a project scaffold from templates.
4. Implement the product with AI-assisted code and architecture.
5. Validate, document, and deploy.

## What the AI handles
- Architecture selection
- Service scaffolding
- Error handling and debugging
- Deployment guidance and CI/CD
- Production readiness and scalability
