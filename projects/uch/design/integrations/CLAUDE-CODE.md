# UCH × Claude Code — Standalone Integration

Part of the UCH Hive Mind (`design/UNIVERSAL-INTEGRATION.md`). Claude Code is
the best-supported runtime: hooks give live events, the transcript gives full
replay including COT, OTel export feeds the trace engine, and the SDK enables
headless drive.

## 1. Mechanism of integration (verified, July 2026)

| Surface | Mechanism | What UCH does |
| --- | --- | --- |
| Live capture | hooks in `.claude/settings.json` (command → `node ~/.uch/hooks/claude-hook.mjs`) | SessionStart/End, UserPromptSubmit, PreToolUse, PostToolUse, Stop, SubagentStop, PreCompact → HiveEvents |
| COT | `thinking` content blocks in transcript JSONL + `Stop` hook (`transcript_path`) | reasoning vault (§UNIVERSAL-INTEGRATION §5) |
| Passive replay | daemon tail of `~/.claude/projects/<encoded>/<session>.jsonl` | full chat logs, usage, costs, tool I/O |
| OTel | `CLAUDE_CODE_ENABLE_TELEMETRY=1` + `OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318` | spans → TraceLedger via daemon OTLP receiver (M2) |
| MCP | `.mcp.json` / `~/.claude.json` / `claude mcp add` | UCH MCP server → all 25+ cognitive tools |
| Instructions | CLAUDE.md hierarchy + `@import` | hive context doc generated by `uch hive init --claude` |
| Drive | `@anthropic-ai/claude-agent-sdk` `query()` | UCH background agents can run Claude Code headlessly |
| Background | `Bash` tool via PreToolUse/PostToolUse | agent shell commands → `background.process` |

## 2. Hooks configuration (generated by `uch hive init --claude`)

`.claude/settings.json` (project-scoped; user-scope in `~/.claude.json`):

```jsonc
{
  "hooks": {
    "SessionStart":   [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" SessionStart" }] }],
    "UserPromptSubmit": [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" UserPromptSubmit" }] }],
    "PreToolUse":     [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" PreToolUse" }] }],
    "PostToolUse":    [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" PostToolUse" }] }],
    "Stop":           [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" Stop" }] }],
    "SubagentStop":   [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" SubagentStop" }] }],
    "PreCompact":     [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" PreCompact" }] }],
    "SessionEnd":     [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" SessionEnd" }] }]
  },
  "env": {
    "UCH_HIVE_URL": "http://127.0.0.1:3999"
  }
}
```

Hook behavior contract:

- Every hook receives the standard JSON on stdin: `session_id`, `transcript_path`,
  `cwd`, `hook_event_name`, `permission_mode` (+ `prompt_id` and tool fields on
  tool hooks, `prompt` on UserPromptSubmit, `stop_hook_active` on Stop,
  `reason` on SessionEnd, `source` on SessionStart, `trigger`/`compact_summary`
  on PreCompact, `subagent_type` on SubagentStop).
- The hook script is **non-blocking**: emits events to the spool and exits 0
  within the default timeout (SessionEnd default 1.5 s — keep it to a single
  append). No `hookSpecificOutput` is ever returned (UCH never gates tools).
- `UserPromptSubmit` + `Stop` give live turn framing; the *complete* message
  content (including `thinking` blocks and `usage`/cost) is read from
  `transcript_path` by the tail ingestor — hooks are triggers, the tail is the
  source of truth. This avoids duplicated capture and survives hook failures.
- `PreToolUse`/`PostToolUse` are used for `tool.call`/`tool.result` +
  `background.process` (Bash); matcher `*` with tool name checked inside, so
  hook config stays static.

Windows note: command hooks run via the configured shell; use
`node "X:/path/to/uch/dist/cli/index.js" hive-hook` style absolute paths, or
`command_windows` overrides where needed.

## 3. Plugin (optional richer surface)

A marketplace/local plugin (`plugin.json`) can bundle the same hooks plus
commands and skills without touching `settings.json`:

```jsonc
{
  "name": "uch-hive",
  "version": "1.0.0",
  "description": "UCH hive mind integration",
  "hooks": { "Stop": [{ "matcher": "*", "hooks": [{ "type": "command", "command": "node \"~/.uch/hooks/claude-hook.mjs\" Stop" }] }] /* … */ },
  "commands": [{ "name": "hive", "description": "Ask the UCH hive", "argument-hint": "[query]", "prompt": "Query the UCH hive mind for context on the user's request..." }],
  "skills": [ /* hive skills dir */ ]
}
```

## 5. CLAUDE.md hive entry

```md
## UCH Hive Mind (managed section — do not edit)

The UCH hive retains memory across all AI tools (Claude Code, Codex, OpenCode,
VS Code Copilot). Before substantial work:

- Ask @hive: `uch_recall <task>` — relevant past sessions, decisions, conventions.
- On completion: `uch_remember decision|convention <text>`.
- When switching tools: `uch handoff <target-tool>`.

@import .uch/hive-context.md
```

`uch hive init --claude` writes `.uch/hive-context.md` (top conventions,
open decisions, recent handoffs) and refreshes it on session start.

## 6. OTel tracing (M2)

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318   # hive daemon OTLP receiver
export OTEL_SERVICE_NAME=claude-code
```

- Claude Code emits prompt/tool/cost spans (correlated via `prompt_id`).
- Daemon maps spans into the existing TraceLedger (OTel schema, ADR-002);
  `trace.span` events carry `prompt_id` so hooks and spans join on
  `provenance.nativeIds.promptId`.
- Claude Code strips `OTEL_*` exporter vars from spawned subprocesses — hooks
  must not rely on them (spool is transport-agnostic, unaffected).

## 7. Drive (hive → Claude Code) via SDK

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";
for await (const msg of query({
  prompt: "…",
  options: { cwd, permissionMode: "acceptEdits", allowedTools: ["Bash", "Read", "Edit", "Grep", "Glob"],
             includePartialMessages: true, maxTurns: 20, agents: { … } },
})) { /* msg.type: assistant | user | system/init | stream_event | result — mirrored to ledger */ }
```

Used by UCH background agents; `result` carries `totalCostUsd`, `durationMs`,
`usage` → `session.end` totals. CLI equivalent:
`claude --output-format stream-json --input-format stream-json --verbose --permission-mode acceptEdits`.

## 8. Testing

- Hook script unit tests (stdin fixture → expected spool lines; latency < 1.5 s).
- Transcript tail fixtures (scrubbed) → HiveEvent parity vs. live hook capture.
- OTLP receiver test with a fake OTLP client; span→ledger mapping assertions.
- E2E (gated, no network): `claude --print "…"` in a sandbox repo with hooks
  installed → ledger shows full session incl. thinking blocks and costs.
