## Neural Pruning (src/physiology/pruning.ts — new)

```ts
export type PruningKind = 'connectome' | 'memory' | 'skill' | 'belief';
export type PruneReason = 'stale' | 'orphan' | 'duplicate' | 'low-relevance' | 'retired';
export interface PruneTarget { kind: PruningKind; id: string; reason: PruneReason; }
export interface PruningReport { targets: PruneTarget[]; merged: number; archived: number; retained: number; at: Date; }
export interface MemorySample { id: string; contentHash: string; relevance: number; updatedAt: Date; }
export interface SkillSample { id: string; name: string; lastUsedAt: Date | null; }
export interface BeliefSample { id: string; claim: string; status: string; confidence: number; }

export class NeuralPruning implements Storable {
  constructor(config: {
    clock: Clock;
    archiveDir: string;                  // mkdtemp in tests; `.uccp/persist/archives/` in prod wiring
    staleHalfLifeMs?: number;            // default 90 days
    staleWeightMax?: number;             // default 0.15 (connectome weights ≤ this AND stale → prune)
    decayThreshold?: number;             // default 0.2 (memory relevance below → archive)
    connectome?: Connectome;
    eventSink?: (event: { type: 'pruned:completed'; payload: { targets: PruneTarget[]; archived: number } }) => void;
  });
  async prune(input: { memories?: MemorySample[]; skills?: SkillSample[]; beliefs?: BeliefSample[] }): Promise<PruningReport>;
  restore(target: PruneTarget): unknown | null;   // reads the archive file back (law:12)
  persist(filePath: string): void;
  load(filePath: string): void;
}
```

- Detection rules (deterministic; all inputs read-only):
  - connectome (when provided): node stale = `lastActivatedAt` older than
    `staleHalfLifeMs` AND weight < `staleWeightMax`; node orphan = has edges
    but no incoming/outgoing neighborhood activity in half-life; dangling
    edges = connectome.checkIntegrity() output → pruned as `stale`.
  - memory: duplicate = same `contentHash` → keep newest, merge = archive the
    older record (counts as `merged`); low-relevance = `relevance <
    decayThreshold` → archive.
  - skill: `lastUsedAt === null` OR older than half-life → archive.
  - belief: `status === 'retired'` → archive + remove from active set (the
    BeliefStore exposes retired records; pruning archives them).
- Every pruned target writes an archive record to
  `${archiveDir}/${kind}-${id}.json` via writeSnapshot — **archived ≠ deleted**
  (law:12); `restore()` reads it back. `retained` = inputs examined minus
  pruned/merged.
- NEVER touches: the workspace genome, immutable laws, any file outside the
  organism's own stores (D-07 lock). Emits `pruned:completed` per run.

- Emits `neuron:created` on creation.

## Belief Objects (src/physiology/beliefs.ts — new)

```ts
export type BeliefStatus = 'tentative' | 'held' | 'contested' | 'retired';
export interface Belief { id: string; claim: string; confidence: number; strength: number; evidence: string[]; source: string; status: BeliefStatus; updatedAt: Date; }

export class BeliefStore implements Storable {
  constructor(config: { clock: Clock; decayHalfLifeMs?: number; retireBelow?: number; holdAbove?: number; eventSink?: (event: { type: 'belief:updated'; payload: { id: string; claim: string; status: BeliefStatus; confidence: number } }) => void });
  add(claim: string, source: string, confidence?: number): Belief;       // default 0.5, status tentative
  updateConfidence(id: string, quality: TakeQuality, now: Date): Belief; // QUALITY_VALUES: 'correct' | 'incorrect' | 'partial' | 'unresolvable'
  decay(now: Date): void;                                                // law:5 — no new evidence → confidence → 0.3 prior, strength halves per half-life
  merge(ids: string[]): Belief;                                          // identical claims → evidence union, confidence = max, strength = sum (capped 1)
  get(id: string): Belief | undefined;
  getActive(): Belief[]; getRetired(): Belief[];
  toTakes(): Take[];                                                     // domain 'belief', conviction = confidence, status open/closed per belief status
  retire(id: string, reason: string): void;
  persist(filePath: string): void;
  load(filePath: string): void;
}
```

- Confidence moves (deterministic, L10 mapping): `correct → +0.10`,
  `incorrect → −0.15`, `partial → +0.02`, `unresolvable → 0`; every update
  appends evidence (`quality:<q>@<now>`), raises strength by 0.05 (capped 1).
- Status transitions: tentative (< 0.4) → held (≥ 0.4) → contested
  (confidence dropped below 0.4 AFTER having been held, or ≥ 2 consecutive
  incorrect) → retired (confidence < retireBelow, default 0.2 — auto-retire
  on update; manual `retire()` for explicit retirement). Emits `belief:updated`
  ONLY on status transitions.
- Decay (law:5): beliefs with no evidence since `updatedAt + decayHalfLifeMs`
  lose `0.5×` confidence per half-life toward the 0.3 prior, strength halves.
- `toTakes()`: `{ claim, conviction: confidence, domain: 'belief', status:
  belief.status === 'retired' ? 'resolved' : 'open' }` — feeds the takes
  fence (precedent: FrameworkDecisionJournal.toTakes + syncTakesWithJournal,
  L10 mapping for resolution: correct→true, incorrect→false,
  partial/unresolvable→null).
- Facts are verified statements; beliefs are hypotheses — the store keeps
  them strictly separate (epistemic distinction, `kernel/epistemic/`).
