### 3. src/cli/daemon.ts (D-07)

```ts
export interface DaemonOptions {
  workspaceId: string;
  workspaceName: string;
  workspaceRoot: string;
  traceFile?: string;   // default join(workspaceRoot, '.uccp/traces.jsonl')
  ticks?: number;       // default 1 — deepSleep cycles before reporting
}

export interface DaemonReport {
  workspaceId: string;
  finalRunning: boolean;        // must be false after clean stop
  sleepCycles: number;
  stats: Record<string, unknown>;
  traceFile: string;
}

export async function runDaemonOnce(options: DaemonOptions): Promise<DaemonReport>
```

`runDaemonOnce` behavior (exact):
1. `const core = new CognitiveCore({ workspaceId, workspaceName, workspaceRoot, traceFile, aetherConfig: { tickIntervalMs: 100 } })` — NO suit, NO LLM, NO drivers.
2. `await core.start();`
3. Loop `ticks` times: `await core.sleepCycle.deepSleep();`
4. `const stats = core.getStats(); const finalRunning = core.getState().running;`
5. `await core.stop();`
6. `process.stdout.write(JSON.stringify({ workspaceId, finalRunning, sleepCycles: ticks, stats, traceFile }, null, 2) + '\n');`
7. Return the report. (If a caller does not want stdout, the test reads it from the child process or calls the module directly — the function is the unit under test.)

CLI wiring (src/cli/index.ts):
- New `case 'daemon':` — parse `--once` and `--ticks N` from `args.slice(2)` (defaults: once=false, ticks=1). With `--once` (or when `--ticks` is given): `await runDaemonOnce({ workspaceId, workspaceName: 'UCH', workspaceRoot, ticks })`. Without `--once`: loop forever with `setInterval`-free async loop (`while (true) { await core.sleepCycle.deepSleep(); await sleep(5000); }` — reuse the module's internal `sleep` helper), stopping on SIGINT (`process.on('SIGINT', ...)` → `core.stop()` → `process.exit(0)`).
- Add `uch daemon` to the help text block.
- The daemon case does NOT touch the top-of-main inline bootstrap (existing behavior for other commands unchanged).
