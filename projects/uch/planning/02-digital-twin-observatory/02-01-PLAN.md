## Types — src/digital-twin/types.ts

```ts
export interface TwinNodeRef { id: string; type: string; name: string; properties: Record<string, unknown> }
export interface TwinEdge { id: string; relationship: string; source: string; target: string; properties: Record<string, unknown> }

export interface TwinSource {
  getNode(id: string): TwinNodeRef | null;
  getEdgesFrom(id: string): TwinEdge[];
  nodeCount(): number;
  edgeCount(): number;
}

export type SimulationKind = 'removal' | 'change' | 'branch';

export interface TwinProjection {
  nodes: TwinNodeRef[];
  edges: TwinEdge[];
  removed: string[];   // node ids removed by the change + cascade
  changed: string[];   // node ids whose properties changed
}

export type RiskLevel = 'low' | 'medium' | 'high';

export interface TwinRisk { level: RiskLevel; reasons: string[] }

export interface SimulationResult {
  query: { kind: SimulationKind; nodeId: string; path?: string };
  projection: TwinProjection;
  impacted: string[];   // BFS-reachable via outgoing edges (excludes the target itself), sorted ascending
  paths: number;        // number of reachable edges traversed (count of edge hops)
  risk: TwinRisk;
  confidence: { value: number; method: 'process_reliability'; calibration_history: unknown[] };
  provenance: { source: string; source_id: string; timestamp: number; reliability: number };
  truncated: boolean;
}

export interface SimulateOptions {
  maxDepth?: number;          // default 3
  maxProjectedNodes?: number; // default 10000
}
```

## DigitalTwin — src/digital-twin/simulator.ts

`class DigitalTwin` — synchronous, deterministic:

| Member | Contract |
|---|---|
| `constructor(source: TwinSource, options?: { maxDepth?: number; maxProjectedNodes?: number })` | wraps the source; defaults maxDepth 3, maxProjectedNodes 10000 |
| `simulateRemoval(nodeId: string, opts?: SimulateOptions): SimulationResult` | if `source.getNode(nodeId)` is null → `{ query, projection: { nodes: [], edges: [], removed: [], changed: [] }, impacted: [], paths: 0, risk: { level: 'high', reasons: ['target-missing'] }, confidence: { value: 0, ... }, provenance: {...}, truncated: false }`. Otherwise run the removal cascade (below). |
| `simulateChange(nodeId: string, properties: Record<string, unknown>, opts?: SimulateOptions): SimulationResult` | target null → same miss shape with kind 'change'. Otherwise: projection copy with target's properties REPLACED by the given object; `changed = [nodeId]`; `impacted` = BFS-reachable via outgoing edges within maxDepth; `removed = []`; risk: high if impacted contains a fan-in node (below), medium if impacted non-empty, else low. |
| `simulateBranch(path: string, opts?: SimulateOptions): SimulationResult` | seed set = every node where `String(node.properties.path ?? '').startsWith(path)` OR `node.name.startsWith(path)` (deterministic, source order). Empty seed → miss shape with kind 'branch' (risk high, reason 'target-missing'). Otherwise run the cascade seeded with the seed set. |
| `getStats(): { simulations: number; byKind: Record<SimulationKind, number> }` | cumulative counters |
| `persist(filePath: string): Promise<void>` | Storable: `writeSnapshot` `{ version: 1, organ: 'digital-twin', stats: getStats(), lastResult?: SimulationResult | null, savedAt: Date }` |
| `load(filePath: string): Promise<number>` | `readSnapshot`; null → 0; else restore stats + lastResult, return `stats.simulations` |

**Removal cascade (LOCKED, D-03):**
1. Frozen copy: `nodes = source` snapshot; incident edges collected via `source.getEdgesFrom(id)` for every node (edges are NOT re-read from a mutating store — the twin builds its own edge adjacency from `getEdgesFrom` per node, so the source only needs getNode/getEdgesFrom/counts).
2. `impacted` = BFS from each seed node along OUTGOING edges (any relationship), depth ≤ maxDepth, excluding seed nodes; visit-set dedupes; `paths` = total edge hops traversed. Order: deterministic — BFS queue order with nodes visited in sorted edge order (edges sorted by target id); final `impacted` sorted ascending.
3. `removed` = seeds + impacted (sorted ascending). Projection = all nodes minus removed; all edges incident to any removed node are dropped.
4. Caps: if `projection.nodes.length` would exceed `maxProjectedNodes` → abort projection to an EMPTY graph (nodes/edges/removed/changed all empty), `truncated = true`, `confidence.value = 0`, risk level 'high' + reason 'cap-exceeded' (impacted/paths still computed).
5. Risk: `high` if any impacted node has > 1 incoming edge (fan-in breakage, reasons `['fan-in:nodeId']`) or truncated or target-missing; `medium` if impacted non-empty (reason `['cascade:N']` where N = impacted.length); else `low` (reason `['leaf']`).
6. `confidence.value = truncated ? 0 : 1`; `method: 'process_reliability'`; `calibration_history: []`.
7. `provenance = { source: 'digital-twin', source_id: \`${kind}:${nodeId}\`, timestamp: <epoch-ms number>, reliability: 1 }`.
8. Determinism: identical source + args → deep-equal results (tests compare `projection.removed`, `impacted`, `risk.level`, `confidence.value`).
