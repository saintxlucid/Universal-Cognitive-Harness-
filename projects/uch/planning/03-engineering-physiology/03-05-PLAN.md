## WorkspaceDNA allele layer (src/workspace-graphs/workspace-dna.ts — additive, in place)
```ts
export type GenomeOutcome = 'merge' | 'bug' | 'rollback' | 'outage';

export interface GenomeAllele {
  id: string;            // deterministic: `${outcome}:${zone}:${at}`
  kind: 'stability' | 'caution';  // merge → stability; bug/rollback/outage → caution
  zone: string;          // affected zone (default 'workspace')
  at: number;            // epoch-ms
  version: number;       // the genomeVersion at mutation time
  outcome: GenomeOutcome;
}

export interface GenomeSnapshot {
  version: number;
  fingerprint: string | null;
  alleles: GenomeAllele[];
  at: number;
  cause: GenomeOutcome;
}

// NEW members on WorkspaceDNA (existing members 100% unchanged: recompute/getFingerprint/getMutations/mutationCount persist/load semantics preserved):
readonly maxSnapshots: number;                       // constructor param, default 100
getGenome(): { version: number; fingerprint: string | null; alleles: GenomeAllele[] };
getSnapshots(): GenomeSnapshot[];
mutate(outcome: GenomeOutcome, zone: string = 'workspace'): GenomeSnapshot;
```
- `mutate(outcome, zone)`: version++; creates allele (kind mapping above, id `${outcome}:${zone}:${at}` with `at = Date.now()`); appends snapshot `{ version, fingerprint: this.fingerprint, alleles: [...current], at, cause: outcome }`; caps snapshots at maxSnapshots (shift-oldest). **CRITICAL: mutate() NEVER calls recompute() and NEVER touches the fingerprint** — the fingerprint is identity over workspace state; alleles are a parallel versioned record (L7, RESEARCH §4.2). Fingerprint stays null-safe (mutation before any recompute → snapshot fingerprint null, still recorded).
- `persist()`/`load()` EXTENDED: persist adds `{ genomeVersion, alleles, snapshots }`; load defaults missing fields to `0`/`[]` (backward compatible — old DNA snapshots load cleanly, L7).
- `getGenome()` returns a copy (immutability).
- No new imports: Date.now allowed here (outcome time — NOT a determinism hazard; tests use explicit sequences, not clock assertions beyond `typeof at === 'number'`).

```ts
export type CortexKind = 'performance' | 'security' | 'product';
export interface PredictionResult {
  cortex: CortexKind;
  risk: number;          // 0-1, higher = worse prediction
  evidence: string[];    // concrete identifiers (metric ids, flag names, rule ids)
  target: string;        // proposal target
}
export interface PredictionInput {
  proposal: WriteProposal;                 // from ../reflex/types.js
  reflex?: ReflexResult;                   // gate result when run
  organic?: OrganicScoreResult;
  judgment?: EngineeringJudgmentResult;
  tasteElegance?: number;                  // 0-100 from taste-engine
}
export class PredictionCortex {
  constructor(config?: { eventSink?: (event: Omit<NeuralEvent, 'id' | 'timestamp'>) => void });
  predict(input: PredictionInput): PredictionResult[];   // ALWAYS 3 results, order [performance, security, product]; SYNC, deterministic
}
```
- Compositor rules (deterministic; evidence locked to identifiers):
  - performance: `risk = clamp(0.5*organicPerformancePenalty + 0.3*organicComplexityPenalty + 0.2*(reflex evidence count / 3))`; penalties derived from organic.metrics entries with id 'performance'/'complexity' (0 when absent); evidence: 'organic:performance', 'organic:complexity', 'reflex:<check_id>' per reflex evidence.
  - security: `risk = clamp(0.4*(judgment.riskLevel === 'high' ? 1 : 'medium' ? 0.5 : 0) + 0.4*organicSecurityPenalty + 0.2*(secret-pattern hit ? 1 : 0))`; secret-pattern hit = SECRET_PATTERNS (import from '../coding/diff-review.js' — runtime const import, no cycle) tested against `proposal.content`; evidence: 'judgment:riskLevel:<l>', 'organic:security', 'secret-pattern'.
  - product: `risk = clamp(1 − (tasteElegance ?? 50)/100)`; evidence: 'taste:elegance:<n>'.
  - `clamp(x) = Math.min(1, Math.max(0, x))`; absent inputs contribute 0 (or neutral per formula) — never throw.
- Recording: when eventSink configured AND any result has `risk >= 0.7`, fire ONE `prediction:made` event per risk result: payload `{ cortex, risk, evidence, target }` (RESEARCH §7 — prediction:made precedent activation-field.ts:253). No new event types.
