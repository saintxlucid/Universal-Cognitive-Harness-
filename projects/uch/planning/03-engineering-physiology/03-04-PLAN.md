New additive surface:
```ts
export interface TasteOutcomeEpisode {
  prId: string;
  patterns: string[];       // canonical pattern ids extracted from the change (e.g. 'factory-method', 'config-object')
  accepted: boolean;        // true = PR merged; false = reverted/changes-requested
  at: number;               // epoch-ms
}

// new members:
readonly episodeThreshold: number;               // default 5 — below this, eleganceScore uses pure cold-start
eleganceScore(input: { text: string; profile?: { functions: Array<{ lines: number }>; files: number[] } }): number; // 0-100
learnFromOutcome(episode: TasteOutcomeEpisode): void;  // raises pattern weights on accepted, lowers on reverted
getEpisodeCount(): number;
getPatternWeights(): Record<string, number>;    // persisted
```
- `eleganceScore` (0-100, deterministic):
  - episodeCount < threshold → cold-start blend: `round(100 * (0.4*namingQuality(extractName(text)) + 0.3*abstractionBalance(text) + 0.3*symmetryIndex(profile ?? { functions: [], files: [] })))` (extractName: first exported-looking identifier — simplest deterministic heuristic: first camelCase token run; a stable helper `firstIdentifier(text)` can be private).
  - episodeCount >= threshold → blended: `round(0.6 * coldStart + 0.4 * learnedScore)` where `learnedScore = 50 + 50 * avg(patternWeights)` (pattern weights 0-1).
  - Deterministic: no Date.now, no random.
- `learnFromOutcome(episode)`: for each pattern: accepted → `weight = min(1, weight + 0.1)`; reverted → `weight = max(0, weight − 0.15)` (asymmetric: pain sticks longer); unknown patterns initialized at 0.5. Appends the episode (capped at 100). No I/O.
- `persist()`/`load()` EXTENDED with `{ episodes: TasteOutcomeEpisode[], patternWeights: Record<string, number> }` — load() defaults missing fields to `[]`/`{}` (backward compatible: old taste snapshots load cleanly).

## PainMemory (src/physiology/pain-memory.ts) — new, Storable
```ts
export type TraumaKind = 'outage' | 'data-loss' | 'security-incident' | 'hard-regression';

export interface TraumaRecord {
  id: string;              // deterministic `${kind}:${zone}:${at}`
  kind: TraumaKind;
  zone: string;            // path zone (e.g. 'src/payments')
  at: number;              // epoch-ms (injectable clock)
  severity: number;        // 0-1
  affect: number;          // decay-resistant initial affect weight (0-1)
  message: string;         // short human text (String()-coerced at the boundary — never raw payload)
}

export class PainMemory implements Storable {
  constructor(maxRecords = 500, options?: { now?: () => number });  // now default Date.now
  recordTrauma(input: { kind: TraumaKind; zone: string; severity?: number; message?: string; at?: number }): TraumaRecord;
  affectFor(zone: string): number;   // max over matching records of DECAYED affect; 0 when none
  getAll(): TraumaRecord[];
  persist(filePath: string): Promise<void>;
  load(filePath: string): Promise<number>;  // missing file → 0
}
export function createZoneAffectFromPain(memory: PainMemory): ZoneAffectProvider; // (zone) => memory.affectFor(zone)
```
- Initial affect (LOCKED, decay-resistant): `base = severity ?? 0.8`; kind multiplier: outage 1.0, data-loss 1.0, security-incident 0.95, hard-regression 0.8; `affect = min(1, base * kindMultiplier)`.
- Decay (LOCKED, decay-resistant): `effectiveAffect(record, now) = affect * 0.9995 ^ ((now − at) / 86_400_000)` — half-life ≈ 3.8 years: permanent bias in practice, mathematically decayed (deterministic, pure math — tests use injectable `now`).
- Record id: `${kind}:${zone}:${at}` (deterministic — no randomUUID; duplicate (kind, zone, at) replaces, matching the phase-01 upsert convention).
- `recordTrauma` with no `at` uses the injectable now; `severity` clamped 0-1; `message` String()-coerced, truncated to 200 chars.
- `affectFor(zone)`: exact-zone match plus prefix match (`zone === r.zone || zone.startsWith(r.zone + '/') || r.zone.startsWith(zone + '/')`) — an outage in 'src/payments' affects 'src/payments/refunds'. Returns the max decayed affect (0 when no records).
- Zero model calls by construction (no provider imports — D-08); pure + sync; Storable via writeSnapshot/readSnapshot.
