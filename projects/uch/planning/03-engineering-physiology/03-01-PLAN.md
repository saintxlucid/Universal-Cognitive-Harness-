## ReflexGate — src/reflex/gate.ts
`class ReflexGate` with synchronous `guard()`:

| Member | Contract |
|---|---|
| `constructor(options?: ReflexGateOptions)` | `ReflexGateOptions { checks?: ReflexCheck[]; disabledIds?: string[]; envKey?: string }` — `envKey` defaults to `'UCH_REFLEX_DISABLE'` (comma-separated check ids + literal `'*'` = all) |
| `register(check: ReflexCheck): void` | adds/replaces a check by `check.id` |
| `guard(proposal: WriteProposal): ReflexVerdict` | runs ALL registered checks in registration order; returns verdict (see below). Never throws for check failures (a throwing check becomes a failed result with severity 'block', mirroring reflex-engine.ts:224-235). |
| `isEnabled(checkId?: string): boolean` | without arg: gate enabled (no `'*'` disable). With id: that check enabled (not in `disabledIds` and gate enabled). |
| `disable(checkId: string, reason: string): void` / `enable(checkId: string): void` | runtime override; `disable('*', reason)` disables the whole gate; `getOverrides()` returns `Record<checkId, { disabled: boolean; reason?: string }>` |
| `getStats(): { totalChecks: number; totalVerdicts: number; blocked: number; deferred: number; allowed: number; byCheck: Record<string, number> }` | cumulative counters |
| `overrideReason(verdict: ReflexVerdict): string \| undefined` | returns the named-override reason if the verdict was reached through `disabledIds`/`disable()` — verdicts from disabled checks carry `override` (see below) |

**Types (all in src/reflex/types.ts):**

```ts
export type ReflexAction = 'create' | 'modify' | 'delete' | 'rename';
export type ReflexVerdictDecision = 'allow' | 'block' | 'defer';
export type ReflexSeverity = 'block' | 'warn' | 'info';

export interface WriteProposal {
  action: ReflexAction;
  filePath: string;                       // workspace-relative or absolute; gate treats as opaque string
  content?: string;                       // present for create/modify
  name?: string;                          // abstraction/name under test (e.g. file basename); default = basename(filePath)
  context?: Record<string, unknown>;      // free-form caller context (e.g. { language, lines })
}

export interface ReflexRuntimeContext {
  existingAbstractions: string[];         // empty [] by default; injected by wiring/caller
  existingDependencies: string[];
  maxFileLines: number;                   // default 400
}

export interface ReflexCheckResult {
  check: string;
  passed: boolean;
  severity: ReflexSeverity;
  message: string;
  evidence: Record<string, unknown>;      // JSON-safe only — never Date, never secrets
  durationMs: number;
}

export interface ReflexCheck {
  id: string;
  description: string;
  severity: ReflexSeverity;
  run(proposal: WriteProposal, ctx: ReflexRuntimeContext): ReflexCheckResult;
}

export interface ReflexVerdict {
  decision: ReflexVerdictDecision;
  results: ReflexCheckResult[];
  blockedBy: ReflexCheckResult[];         // failed && severity 'block'
  deferredBy: ReflexCheckResult[];        // failed && severity 'warn' (defer = escalate to judgment tier)
  proposal: WriteProposal;
  override?: { checkId: string; reason: string };  // set when a blocking check is disabled via override
  at: number;                             // epoch-ms number
}
```

**Decision rules (LOCKED):**
1. Any failed check with severity `'block'` → `decision: 'block'`; `blockedBy` = all such results (not just the first).
2. Else any failed check with severity `'warn'` → `decision: 'defer'`; `deferredBy` = all such results.
3. Else → `decision: 'allow'`.
4. `'info'`-severity checks never affect the decision; their results are still returned in `results`.
5. A check whose id is disabled (via `disabledIds`, env `UCH_REFLEX_DISABLE`, or `disable()`) is SKIPPED (not run) and does not appear in `results`; if the verdict would have been 'block' only because of skipped checks, the verdict is `'allow'` and `override` is set with the FIRST disabled blocking-check id + reason.
6. `guard()` is deterministic: same proposal + same ctx + same gate state → identical decision/results.
