## src/reflex/gate.ts — beyond the 03-01 contract
- `evaluate()` evaluation order: checks run in registry order; ALL checks run (evidence from every flagged check is collected — a blocking check does not short-circuit collection); verdict = block if any block evidence (after escalation), else defer if any defer evidence, else allow.
- Escalation runs once per evaluate BEFORE verdict computation: for each evidence with `level: 'defer'`, if `ctx.zoneAffect(zoneOf(proposal)) >= PAIN_ESCALATION_THRESHOLD`, its level becomes 'block' (evidence object mutation must not corrupt the check's own state — clone the evidence entry when escalating).
- Escape hatch: `override.enabled !== false` and (names includes the check id or '*') → the check's evidence is suppressed from the verdict but kept in the record; `result.override = { name: <first suppressed check id>, recorded: true }`; the eventSink block record payload gains `override: { name, recorded: true }`. Env `UCH_REFLEX_OVERRIDE` (comma-separated ids or '*') is read once in the constructor and merged with config names (constructor is the only place process.env is read — keeps evaluate() pure/deterministic).
- Event sink payloads (LOCKED, no new event types — D-04):
  - block: `{ type: 'governance:event_denied', source: 'reflex-gate', payload: { gate: 'reflex', tool, target, check_id: <first block check>, rule: <its rule>, evidence: <string[] from that entry>, threshold, reason, override? } }`
  - defer: `{ type: 'review:requested', source: 'reflex-gate', payload: { tool, target, checks: <deferring check ids>, reason } }`
  - allow: `{ type: 'tool:called', source: 'reflex-gate', payload: { tool, target, verdict: 'allow', checks_run, duration_ms } }`
  - Signal sink (block only): `createSignal('error:occurred', 'reflex-gate', { ...payload, verdict: 'block' }, { interrupt: true, interruptLevel: 2 })` — brainstem tier (L5). defer signal: `createSignal('review:requested', 'reflex-gate', { ...payload, verdict: 'defer' }, { interrupt: false })`.
- `PAIN_ESCALATION_THRESHOLD = 0.7` exported const.
- No `Date` in payloads; duration_ms = `Date.now() - start` (number).

## src/reflex/checks.ts — the 4 canonical checks (D-03 specifics)
Signature: `createReflexChecks(options: { knowledgeGraph?: Pick<WorkspaceKnowledgeGraph, 'search' | 'findArtifacts'>; decisionGraph?: Pick<WorkspaceDecisionGraph, 'search'>; grant?: { workspace: string; scope: CapabilityScope } | null }): ReflexCheck[]`

1. `duplicate-abstraction` (rule 'duplicate-abstraction-overlap', level block, threshold 'overlap>=0.6'): basename tokens from `path.basename(proposal.target)` split on camelCase/snake/kebab → lowercase tokens; union of `knowledgeGraph.search(token)` + `decisionGraph.search(token)` hits (search is sync — GraphStore LIKE over names + JSON props, knowledge-graph.ts:115); hit overlaps proposal basename when any hit node name shares ≥60% of the proposed basename's tokens (hit token set ∩ proposal token set / proposal token count ≥ 0.6); evidence = hit node ids. No graphs → null (pass). Note: `search` is sync on the real GraphStore (DatabaseSync); the check signature stays sync.
2. `duplicate-dependency` (rule 'dependency-inventory-collision', level block, threshold 'import-collision'): parse import specifiers from `proposal.content` (regex: `/^\s*import\s+.*?\s+from\s+['"]([^'"]+)['"]/gm` + `require('...')`); for each specifier, if the basename of the specifier matches an artifact name returned by `knowledgeGraph.search(basename)` AND the artifact's path is NOT `proposal.target` → evidence = artifact node ids + `import:<specifier>`. No content or no graphs → null.
3. `complexity-threshold` (rule 'line-complexity-threshold', level block, threshold 'lines>=400'): `proposal.content` line count ≥ 400 → block with evidence `['lines:<n>']`, threshold `'lines>=400'`; also flags ≥ 25 functions (`/function\s+\w+\s*\(|=>\s*{/gm` count) as defer evidence with threshold 'functions>=25' (defer, not block — judgment tier reviews it). No content → null.
4. `ownership-boundary` (rule 'ownership-scope-violation', level block): `grant.scope.project` (or `grant.scope.branch`) present → resolve `proposal.target` against the workspace root prefix `grant.scope.workspace`; if target path does not start with the project pin (`/projects/<project>/` pattern from scope.project) → block with evidence `['scope:project:<project>', 'target:<target>']`. No grant/scope pins → null (pass). The check reads ONLY grant metadata — zero ProjectionEngine instantiation (L6: no I/O).
