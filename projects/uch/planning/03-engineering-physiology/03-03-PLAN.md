- `abstractionBalance(text)`: count OVER_ABSTRACTION phrase hits (from organic-score exports) vs UNDER_ABSTRACTION hits; no hits → 0.5 (neutral); over-dominant → low, under-dominant → low, balanced → high. Formula: `hits = over + under`; `balance = 1 − |over − under| / (over + under)`; `score = 0.5 * balance` when hits > 0 else 0.5 (deterministic, monotonic).
- `symmetryIndex(profile)`: 1 − normalized variance of function line counts and file sizes: compute coefficient of variation (std/mean) over `[...functions.map(f => f.lines), ...files]`; empty → 1; single element → 1; `score = Math.max(0, 1 − cv)`.

## src/physiology/counterfactual.ts — five futures
```ts
export type FutureKind = 'debt' | 'security' | 'scale' | 'maintainability' | 'preferred';
export interface FutureVerdict {
  future: FutureKind;
  score: number;          // 0-100, higher = better outcome for that future
  evidence: string[];     // concrete: metric ids, judgment flags, veto names
  basis: string;          // which input sources produced this score (e.g. 'organic:complexity,judgment:riskLevel')
}
export interface CounterfactualInput {
  proposal: WriteProposal;                       // from ../reflex/types.js
  organic?: OrganicScoreResult;                  // type-only import
  judgment?: EngineeringJudgmentResult;          // type-only import
  metrics?: { naming: number; abstraction: number; symmetry: number };
}
export interface CounterfactualResult {
  futures: FutureVerdict[];                      // ALWAYS length 5, order debt, security, scale, maintainability, preferred
  recommended: FutureKind;
  recommendedScore: number;
}
export class CounterfactualEngine {
  evaluate(input: CounterfactualInput): CounterfactualResult; // SYNC, deterministic
}
```
- Scoring rules (deterministic compositions; weights are module constants — export `COUNTERFACTUAL_WEIGHTS` for tests):
  - debt: `100 − 25*(organic debt markers normalized) − 15*judgment.flags.length − 10*(judgment.score < 0.5 ? 1 : 0)`; evidence: 'organic:future-readiness', 'judgment:duplicate-abstraction', 'debt-marker:<text>' (first 3 markers).
  - security: `100 − 30*(judgment.riskLevel === 'high' ? 1 : riskLevel === 'medium' ? 0.5 : 0) − 20*(organic security veto ? 1 : 0)`; evidence: 'judgment:riskLevel:<level>', 'organic:security' (+ veto name when present).
  - scale: `100 − 20*organic.performancePenalty − 10*organic.complexityPenalty` (derive penalties from the organic metrics array by metric id); evidence: 'organic:performance', 'organic:complexity'.
  - maintainability: `100 − 15*(1 − metrics.naming) − 10*(1 − metrics.symmetry) − 15*(1 − metrics.abstraction) − 5*organic.couplingPenalty`; evidence: 'metrics:naming:<n>', 'metrics:symmetry:<s>', 'metrics:abstraction:<a>'.
  - preferred: `100 − (100 − mean(other four scores)) * 0.6 − 10*(organic veto ? 1 : 0)`; evidence: 'constitution-aligned', 'aggregate:<mean>'.
  - Missing inputs: any absent source contributes ZERO penalty (documented in `basis` as 'absent:<source>') — the engine never throws on partial input; determinism holds.
- Recommended rule (LOCKED, D-05 'picks by constitution alignment, not by likelihood'): `recommended = argmin over futures of score` with FIXED tie-break order `['debt', 'security', 'scale', 'maintainability', 'preferred']` — the worst future (lowest score) drives the recommendation (worst-case reasoning); `recommendedScore = score(recommended)`. If a future score is undefined/NaN → treat as 100.
- `evaluate` is SYNC and pure: no Date.now, no random, no I/O, no model calls. The optional LLM future path is deliberately NOT part of this class (documented in the design doc — gated above the reflex tier, 03-CONTEXT D-05).
