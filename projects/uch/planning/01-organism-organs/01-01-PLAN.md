## Shared rules (all 5 organs)
- Class implements `Storable` from `src/cognitive-plane/persistence/persistence-engine.ts`: `persist(filePath): Promise<void>` + `load(filePath): Promise<number>`.
- `load` on a missing file returns 0 (readSnapshot returns null → 0).
- All node/edge ids deterministic. NEVER `crypto.randomUUID()` in organ source (tests may use fixed strings).
- Node/edge `properties` hold ONLY JSON-safe values — never `Date` objects (GraphStore JSON-serializes properties; timestamps live in `created_at`/`valid_at` as epoch-ms numbers).
- Node-type vocabulary per organ (see tables below); edge `properties` for provenance-bearing edges:
  `{ provenance: { source: string, source_id: string, timestamp: number, reliability: number }, confidence: { value: number, method: 'process_reliability', calibration_history: [] } }`
- GraphStore SQLite file is created at `join(basePath, '<organ-slug>')/graph.sqlite` on construction.
